IP


Muestra la dirección IP registrada como la suya (la única autorizada para entrar al panel de administración) y su IP actual.


Si ve "Access denied: wrong IP address": su conexión actual no coincide con la registrada — esto pasa si viajó o cambió de red. La contraseña no ayuda en este caso, ya que el sistema revisa la IP primero.


Normalmente esto se actualiza solo cada mañana mediante una herramienta llamada updateMyIP.php.

Esta misma herramienta puede abrirse manualmente desde cualquier dispositivo o lugar — incluso viajando — para declarar su ubicación actual a ambos sitios.


El enlace exacto está guardado en Roboform:

buscar por updateMyIP.php. y hacer doble clic en el nombre. Se abre una página web que muestra el número IP anterior y actualizado, y confirma la asctualización.
